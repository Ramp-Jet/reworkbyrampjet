# Fonts

Self-hosted WOFF2 subsets used by `index.html` and
`rework-advisor-one-pager.html`.

| Family | Files | License |
|---|---|---|
| **IBM Plex Mono** (400/500/600/700) | `ibm-plex-mono-*.woff2` | SIL OFL 1.1 — `OFL-IBM-Plex.txt` |
| **IBM Plex Sans** (variable) | `ibm-plex-sans-var-*.woff2` | SIL OFL 1.1 — `OFL-IBM-Plex.txt` |
| **Archivo** (variable) | `archivo-var-*.woff2` | SIL OFL 1.1 — `OFL-Archivo.txt` |

The OFL requires that a copy of the license accompany the font files wherever
they are redistributed. This repo is public and serves reworkbyrampjet.com, so
keep these license files next to the `.woff2` files they cover.

Sources: https://github.com/IBM/plex and
https://github.com/Omnibus-Type/Archivo
